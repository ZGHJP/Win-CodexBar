# Win-CodexBar 0.70.0-jp.6

Windows x64 自用维护版，2026-11-14。修复 jp.5 遗留的凭据硬链接问题；新安装和升级请使用本版。

## 凭据与旧安装迁移

- 修复 `persist_failed` / `atomic credential replacement does not support hard-linked files`：兼容层不再创建任何硬链接。凭据和配置使用受源文件访问权限保护的独立文件，通过原子替换更新；原始 Codex 文件不被替换或改写。
- 认证更新会在下一轮整理时同步，通常约 15 秒；原始凭据删除后移除兼容副本，防止继续使用已退出的登录。
- 日志数据库用 SQLite backup 生成包含已提交 WAL 数据的一致性快照，不复制正在写入的主库和 WAL/SHM 文件组合；最多每 5 分钟更新，每次尝试限时 5 秒；普通 tokens 仍来自整理后的请求日志。
- 升级会清理本用户标准目录及 `OpenAI.Codex_*` 商店版缓存目录内属于旧兼容层的硬链接，并更新可识别的旧辅助脚本，保留脚本备份。仅移除兼容目录中的链接项，不删除原始凭据、数据库或回收站内容。
- jp.5 及更早版本仍可能重建硬链接。手工断开一次不能代替升级代码。该修复只处理本工具拥有的兼容目录；其他软件创建的链接需另行核对。

## 保留的每日费用修复

- 本地日志独立于远端配额的更新时间刷新；窗口持续打开时每分钟检查，恢复焦点或可见后补读，重复唤醒事件合并。
- 顶部费用汇总缓存最多复用一分钟，避免远端配额没有变化时无限复用旧金额；常规重新读取仍遵守扫描器的缓存与工作量限制。
- 先完成本地扫描，再读取 Codex 周期聚合，避免将上一轮缓存标为本轮结果。沿用新版上游 `snapshot_around_local_scan` 的顺序设计，Claude 仍先建立供扫描使用的快照。
- 桌面遇到暂时不可用或无进展的费用扫描时，保留已有记录，限频重试；不修改核心扫描器其他调用者的暂停策略，不把每轮刷新都强制为完整扫描。
- 整理后的请求日志使用独立费用缓存及唯一扫描来源，避免原始与整理后的同一会话同时进入继承计数。移除兼容目录里由旧辅助程序创建的原始目录索引硬链接；原始文件、原缓存和用户设置保留。
- 首次安装会导入近 31 天的压缩日志，覆盖每日图表的 30 天范围；已知历史会话继续保留。
- 价格目录刷新失败时，Codex 可使用最近 30 天内成功获取的 OpenAI 公开费率继续估算，并显示目录日期及“缓存估算”提示；后台继续限频续取。没有有效费率的模型仍不猜价，其他提供者的缓存策略不变。
- GitHub 安装包带构建时下载的公开价格目录，首次安装不依赖目标电脑能立即连接价格站点；已有更新目录不被旧目录覆盖。
- 价格站点不可用时，从 models.dev 官方 GitHub 仓库读取公开费率；辅助进程每 15 分钟检查一次，目录满 24 小时才续取，下载失败保留原目录，不阻塞本地用量更新。GitHub 费率中的长上下文门槛按原值保存，不再假定为 200K。
- 包含此前 jp.4 的账户隔离、周期重建及加载快照修复。基线仍为 v0.70.0，已核对上游至 fd06294；这是经过针对性移植的维护版，不宣称包含新版上游所有功能。
- 安装包包含独立 Python 运行时和压缩读取依赖，无需安装 Python、Rust 或 Visual Studio。保留 MIT 与 Python/依赖许可证。

## 在其他电脑使用

1. 下载 Release 的 `CodexBar-0.70.0-jp.6-windows-x64.zip` 并解压整个文件夹。
2. 退出已有 CodexBar，等待所有旧辅助进程结束（约 45 秒），运行 `Install.cmd`。商店版缓存目录内的旧安装也会迁移。
3. 使用该电脑自己的 Codex 登录及本地日志。安装包不含原电脑的账户、会话、用量数据库或设置；历史用量不会自动跨电脑同步。

支持 Windows x64，需系统 WebView2 Runtime（Windows 11 通常已具备）。安装按当前用户进行，不要求管理员权限。自用 EXE 未签名；安装脚本验证包内 SHA256，Release 另附 ZIP 校验值。自动下载上游更新应保持关闭，防止覆盖个人修复。

美元金额仍是 API 等价估算，不是订阅或 credits 实际账单；未重写 Fast 或套餐计费，也未手填模型单价。来源不足的金额继续显示 `—` 或估算标记，不能补成零。

安装前备份旧程序，保留设置和原始日志。需要回滚时退出程序，恢复安装目录备份；不删除使用记录或认证文件。详细测试见 `personal/VALIDATION.md`。
